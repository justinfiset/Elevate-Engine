\page webassembly Building with Emscripten

- Install the emsdk using the [Emscripten SDK Download and Install Guide](https://emscripten.org/docs/getting_started/downloads.html).
- Activate the emsdk environment so `emcc`, `em++` and `emscan-deps` are available.
- Configure and build with the `web` preset:

```bash
cmake --preset web
cmake --build Build/web --config Release
```

The preset uses the Emscripten toolchain directly. Do not wrap the configure step with `emcmake`, because it can override the generated build system.

The HTML shell, web assets and `--preload-file` arguments are generated by CMake. Outputs are written to:

```text
Build/bin/<Configuration>-emscripten-wasm32/<Project>/
```

Use `Editor_Debug` or `Editor_Release` for editor-capable builds and `Release` or `Dist` for runtime builds.
